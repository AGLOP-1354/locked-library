# 디자인 시스템 — "밤의 서재"

레퍼런스와 근거: `docs/design-references.md`. 캔버스 시안: https://claude.ai/artifact/PSdoXpNyv7wBJmNWZMDs3P
새 화면 작업 전 `frontend-design` 스킬을 함께 쓴다.

## 무드
불 꺼진 서재, 오래된 천 장정, 바랜 금박. 공포는 **암시**로 — 피 튀기는 연출, 글리치, 점프 스케어 금지.
**힘은 한 곳에만**: 메인의 시그니처는 책장(세로 제목 책등)이다. 나머지는 조용하게.

## 문구 (중요)
- 사용자가 바로 알아듣는 쉬운 말만 쓴다. "서가", "열린/잠긴 서가" 같은 비유어 금지.
- 고정 용어: 메뉴 **모든 책 / 공개 예정**, 책장 제목 "영상으로 만난 책", 꼬리표 **무료 원문 / 한국어판**. "무료 책/유료 책"으로 나누지 않는다.
- 책 버튼은 어디서나 `BookActions` 하나로: 첫 줄 **영상 보기**(금색), 둘째 줄 **영어 원문 읽기**(회색 테두리) | **한국어판 구매**(금색 테두리). 둘째 줄은 있는 것만, 하나면 한 줄을 다 쓴다. 구매 버튼이 있으면 아래에 출판사·수수료 안내 한 줄.
- 원문 버튼 이름(언어, 번역본 여부)은 `readLabel()`이 만든다. 외부로 나가는 링크엔 바깥 화살표 아이콘.
- 말투는 부드러운 해요체. 빈 상태는 다음 행동을 알려 준다 ("첫 책이 곧 올라와요. 구독하면 알려 드릴게요").
- 대문자 라벨, 'A · B · C' 식 나열, 버튼 끝 '→' 쓰지 않는다.

## 색 (토큰만 — `src/app/globals.css`의 `@theme`)
| 토큰 | 용도 |
|---|---|
| `ink` / `ink-deep` / `ink-raised` | 바탕 / 구분 섹션 바탕 / 입력창·메뉴 |
| `line` / `line-strong` | 구분선 / 입력창·칩 테두리 |
| `wood` / `wood-edge` | 책장 선반 |
| `paper` / `paper-soft` / `paper-dim` | 제목 / 본문 / 보조 글자 |
| `brass` (+`brass-hover`, `brass-line`) | 주요 버튼, 링크, 포커스, 한국어판 꼬리표·구매 버튼 |
| `moss` (+`moss-line`, `moss-bg`) | 무료 원문 꼬리표 |
| `cloth-*` (oxblood, bottle, navy, ochre, plum, rust, slate, vellum) | 책등·표지 천 색 |
| `foil` / `foil-ink` / `cover-title` | 책등 금박 글자 / 밝은 천 위 글자 / 표지 제목 |

- **Tailwind는 클래스 이름에 보이는 색만 CSS에 남긴다.** `style={{ background: "var(--color-…)" }}`처럼 동적으로 쓰면 색이 사라진다. 천 색은 `src/lib/cloth.ts`의 `CLOTH_BG` 표로 클래스를 고른다.
- 대비 4.5:1 이상. paper-dim(보조 글자)도 바탕 대비 약 6.8:1. 천 위 금박 글자는 6:1 이상으로 맞춘 색만 쓴다.

## 글꼴
- `font-serif` = 함렛(Hahmlet): 책 제목, 섹션 제목, 책 소개 문장, 책등 세로 제목.
- `font-sans` = IBM Plex Sans KR: 메뉴, 버튼, 보조 정보.
- 한국어는 `word-break: keep-all`(body에 적용)로 어절 단위 줄바꿈.
- 책 소개는 행폭 34em 이하, 줄간격 1.8.

## 레이아웃
- 모바일 우선, `md`(768px)에서 데스크톱. 좌우 여백 모바일 16px / 데스크톱 40px, 최대 폭 `max-w-7xl`.
- 가로 스크롤은 책장, 장르 버튼, 모바일 메뉴 칩에만. 페이지 전체 가로 스크롤 금지.
- 메인 순서: 최신 영상 → 지난 영상 → 영상으로 만난 책(책장) → 공개 예정 → 바닥글. 책이 없는 섹션은 메인과 헤더 메뉴에서 함께 숨긴다.
- 책장 거르기 버튼(무료 원문, 한국어판, 장르)은 실제로 걸러지는 경우에만 보인다.
- 책 페이지 순서: 영상(누르면 재생) + 제목·소개·읽기 버튼 → 영상 차례 → 원작 이야기 → 다른 책.
- 무료 원문/한국어판은 `BookTags`로 색 + 글자 함께 표시.
- 책등 크기는 `spineSize()`가 제목 길이로 계산한다(세로 제목이 잘리지 않게). 제목 글꼴·크기를 바꾸면 이 계산의 숫자도 다시 잰다.

## 모션
- 책등: 누르면 위로 빠져나옴, 마우스를 올리면 살짝 들림 (300ms). 그 외 장식 모션 없음.
- `prefers-reduced-motion`이면 모든 전환을 끈다 (globals.css).

## 접근성
- 버튼은 `<button>`, 이동은 `<a>`. 아이콘만 있는 버튼은 `aria-label`. 터치 영역 44px 이상.
- 포커스 링 `brass` 2px (globals.css `:focus-visible`), 지우지 않는다.
- 선택 상태는 `aria-pressed`, 펼침은 `aria-expanded`, 바뀌는 소개는 `aria-live="polite"`.
